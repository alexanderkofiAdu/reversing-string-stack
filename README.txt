STRING REVERSAL USING A STACK
==============================

Files
-----
- reverse_stack.html: The complete web form (HTML, CSS, and JavaScript).

How to run
----------
1. Extract the ZIP folder.
2. Open reverse_stack.html in any modern web browser.
3. Enter a word or sentence.
4. Click "Reverse String" to see the reversed result.

How it works
------------
1. Each character is pushed onto a stack.
2. Characters are popped from the stack one by one.
3. Because a stack follows Last In, First Out (LIFO), the output is reversed.

This project runs locally and does not require an internet connection or installation.
